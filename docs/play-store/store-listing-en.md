## Full description

```
Gatekeep is screen-time management on your own device: choose apps, set limits, and get overlays when time is up — not just quiet notifications.

LIMITS & PROFILES
• Daily, weekly, hourly, and per-session limits; mandatory breaks where you configure them
• Multiple profiles with optional per-profile PIN lock
• Schedule segments through the day with customize / block / default modes per window

ENFORCEMENT
• Block overlay on monitored apps when rules say stop
• Unblock or continue with a math challenge, a timed wait, or a password
• Optional on-open math or wait before launching (per profile rules)
• Session HUD bar while a tracked app is in the foreground (toggle in Settings)
• Pause 5, 15, or 60 minutes; focus block; emergency bypass (global pause screen)
• Strict mode (app PIN for profile edits) and optional device admin uninstall deterrent

INSIGHTS & TOOLS
• Usage statistics with streaks and bar charts
• Pick which apps each profile monitors; tune default and per-window rule presets
• Optional weekly usage summary notification

Accessibility and usage-access permissions are required for enforcement — you grant them during setup.

Questions or feedback: developer contact on this Play listing.
```
